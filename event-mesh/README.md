# Event Mesh extension

Phase 9.1 is **closed with an environment limitation**: owner read-only checks found SAP Event Binding and `/IWXBE/CONFIG` AMQP tooling and a Cloud Integration AMQP adapter, but no assignable Event Mesh entitlement in the currently inspected BTP environment. Phase 9.2 is a **local-only** contract/consumer-semantics proof. Phase 9.3's RAP DeliveryIntent business-event producer is **implemented and locally verified in A4H**. Phase 9.4's PIH-owned Event Binding `ZJPEBPODLVREQ` is **active**, with generated external type `zjp.PurchaseOrder.DeliveryRequested.v*` (version `0001 / 0 / 0`), but external publication is **environment-blocked**. No PIH-owned broker, service key, AMQP channel, outbound binding, queue, Cloud Integration consumer, or production callback exists yet.

See the [9.1 offering and architecture record](docs/phase-9-1-foundation.md), [9.2 event contract/test record](docs/phase-9-2-event-contract.md), [9.3 SAP producer evidence](docs/phase-9-3-rap-producer.md), and [9.4 binding evidence](docs/phase-9-4-event-binding.md). `payloads/` contains a versioned **logical** schema and synthetic fixtures; `src/` and `test/` contain an isolated TypeScript decision simulator. Run its tests with `node --experimental-strip-types --test event-mesh/test/consumer.test.mts` from the repository root. The real broker/publication path remains environment blocked.

The active A4H producer uses DeliveryIntent CREATE in managed additional save; the event key is DeliveryUUID and its parameter contains PurchaseOrderUUID, OrderRevision, and PayloadHash. The broader [event architecture](../ARCHITECTURE.md#event-driven-extension-phase-9) predates the current lifecycle finding: `PurchaseOrderApproved` must not itself trigger delivery. The Phase 9.2 logical contract is `PurchaseOrderDeliveryRequested.v1`, referring to the committed DeliveryIntent; the authoritative generated external type is `zjp.PurchaseOrder.DeliveryRequested.v*`. The three green ABAP Unit methods prove saver emission/count/payload and CREATE-vs-UPDATE gating only, not external publication or rollback semantics.
